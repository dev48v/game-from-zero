🔨 Build it yourself

    
An idle clicker has no engine and no sprites — it is pure economy math. The whole game is a handful of numbers, one requestAnimationFrame loop that pays you production × elapsed-seconds every frame, a geometric ×1.15 price curve that keeps every purchase a decision, and a prestige reset that trades your run for a permanent multiplier. About 120 lines of vanilla JavaScript, no libraries, saved to localStorage. Copy each block in order.

    
    

      
  1. 
        
    1
    The whole game is a few numbers
    
        
    No world, no physics. The entire state is: how much ore you hold now, how much you've earned this run (that drives prestige), how many of each generator you own, your click level, and your permanent gems. Everything on screen is just a formatted view of these variables, which is why the game saves to one small string.
    
        
    const GENS = [
  { name:"Apprentice", icon:"⛏️", baseCost: 15,      rate: 0.1  },
  { name:"Ore Cart",   icon:"🛒", baseCost: 110,     rate: 1    },
  { name:"Power Drill", icon:"🔩", baseCost: 1200,   rate: 8    },
  { name:"Excavator",  icon:"🚜", baseCost: 13000,   rate: 47   },
  { name:"Mine Shaft", icon:"🕳️", baseCost: 140000,  rate: 260  },
  { name:"Quarry",     icon:"⛰️", baseCost: 1600000, rate: 1400 },
];
let ore, earnedThisRun, count, clickLevel, gems;

function freshRun(){          // wiped on prestige (gems survive)
  ore = 0; earnedThisRun = 0;
  count = GENS.map(() => 0);
  clickLevel = 0;
}

    The tick loop earns over real time
    
        
    A clicker must pay you even when you're not clicking, so the heart of the game is a requestAnimationFrame loop. Each frame we measure dt — the real seconds since the last frame — and add production × dt. Multiplying a per-second rate by elapsed seconds makes income frame-rate independent: 60fps or 30fps, you earn the same per real second. This exact trick pays offline time by treating your absence as one giant dt.
    
        
    let last = performance.now();

function loop(now){
  const dt = (now - last) / 1000;   // real seconds elapsed
  last = now;
  const gained = perSec() * dt;     // rate x time = ore
  ore           += gained;
  earnedThisRun += gained;
  render();
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

    Clicking mints the base resource
    
        
    The very first ore comes from your own taps. Each click adds clickPower, which starts at 1 and grows by upgrades. Clicking is the bootstrap: before you own a single generator, tapping the rock is the only income and the only way to afford your first miner. It's also multiplied by the prestige bonus, so it never becomes completely worthless.
    
        
    function clickPower(){
  return (1 + clickLevel) * prestigeMult();   // base 1, +1 per level
}
function mine(){
  const g = clickPower();
  ore += g; earnedThisRun += g;
}

    4
    Generators auto-produce per second
    
        
    The instant you buy a generator it starts digging on its own. Total production per second is simply the sum, over every type, of its rate times how many you own — one Apprentice adds 0.1/s, one Cart 1/s. That single number is what the tick loop multiplies by dt every frame. The whole prestige bonus multiplies it at the end.
    
        
    function perSec(){
  let sum = 0;
  for (let i = 0; i < GENS.length; i++)
    sum += GENS[i].rate * count[i];   // rate x how many you own
  return sum * prestigeMult();
}

    Exponential cost scaling (×1.15)
    
        
    If generators cost the same forever, you'd buy infinite ones instantly and the game would end. The golden rule of the genre: each copy costs 15% more than the last, so the price of the n-th unit is baseCost × 1.15ⁿ. That geometric curve snowballs far faster than your linear income, forcing you to keep unlocking bigger generators instead of spamming the cheapest. Buying just subtracts the current price and increments the count.
    
        
    const GROWTH = 1.15;

function genCost(i){
  return GENS[i].baseCost * Math.pow(GROWTH, count[i]);
}
function buyGen(i){
  const c = genCost(i);
  if (ore < c) return;      // can't afford
  ore -= c; count[i]++;      // next one costs 15% more
}

    ROI — is a purchase worth it?
    
        
    With prices climbing, "what next?" becomes a real decision, and the tool is payback time: divide a purchase's cost by the extra ore-per-second it grants and you get how many seconds until it pays for itself. A drill costing 1,200 that adds 8/s pays back in 150s; if a cheaper generator pays back faster, buy that first. Skilled idle play is really just minimizing payback every purchase — the same ROI math businesses use for capital, hiding in a game.
    
        
    function paybackSeconds(i){
  const extraPerSec = GENS[i].rate * prestigeMult();
  return genCost(i) / extraPerSec;   // cost / income = seconds to break even
}
// lower payback = better buy right now

    Compounding — machines buy machines
    
        
    The reason idle numbers explode is compounding. Ore from your generators buys more generators, which produce more ore, which buys still more — a feedback loop where the growth rate itself grows. Unlike your fixed click, automated income feeds back into itself. It crawls early, then curves sharply upward as each layer funds the next. That reinvestment loop is why the second half of every run is dramatically faster than the first.
    
        
    // the loop that never stops paying:
//
//   ore  --buy-->  generators  --perSec()-->  more ore
//    ^                                           |
//    +-------------------------------------------+
//
// perSec() rises every purchase, so the NEXT purchase
// arrives sooner, so perSec() rises faster still.

    Prestige — burn it down for a permanent bonus
    
        
    Eventually costs outrun income and progress crawls. Prestige is the escape valve: reset the whole run — ore, generators, upgrades all to zero — in exchange for permanent gems. Gems are a square-root of what you earned this run, √(earned ÷ 2,500), so they come from big, diminishing milestones, and each adds +2% to all future production forever. You return weaker on paper but with a multiplier that makes the next climb far faster. Knowing when to prestige is the genre's deepest decision.
    
        
    function pendingGems(){
  return Math.floor(Math.sqrt(earnedThisRun / 2500));
}
function prestigeMult(){
  return 1 + gems * 0.02;        // +2% per gem, permanent
}
function prestige(){
  const g = pendingGems();
  if (g < 1) return;             // need at least one gem
  gems += g;                     // gems survive...
  freshRun();                    // ...everything else resets
}

    Formatting huge numbers (K/M/B/T)
    
        
    Idle games race past a billion within minutes, and 1400000000 is unreadable. Every number on screen passes through a formatter that divides by a thousand repeatedly, counting suffixes — K, M, B, T and beyond — and prints two decimals. Below a thousand we show the raw value. This is pure presentation, applied only when drawing, never to the stored numbers, so full precision is preserved underneath.
    
        
    function fmt(n){
  if (n < 1000){
    return (n < 100 && n % 1 !== 0) ? n.toFixed(1)
                                     : Math.floor(n).toString();
  }
  const u = ["K","M","B","T","Qa","Qi","Sx"];
  let i = -1;
  while (n >= 1000 && i < u.length - 1){ n /= 1000; i++; }
  return n.toFixed(2) + u[i];      // 1400000000 -> "1.40B"
}

    Save, load, and pay offline time
    
        
    Persistence is what makes an idle game idle. Autosave the state (plus a timestamp) to localStorage every few seconds. On load, restore it, then compute how many seconds passed while you were gone and grant perSec() × offlineSeconds — capped so a month away doesn't overflow. Now the mine literally earns while the tab is closed, and the delta-time loop keeps earning while it's open.
    
        
    const KEY = "idle_mine";

function save(){
  localStorage.setItem(KEY, JSON.stringify(
    { ore, earnedThisRun, count, clickLevel, gems, ts: Date.now() }));
}
function load(){
  const s = JSON.parse(localStorage.getItem(KEY) || "null");
  if (!s){ freshRun(); gems = 0; return; }
  ({ ore, earnedThisRun, count, clickLevel, gems } = s);
  const away = Math.min((Date.now() - s.ts) / 1000, 8 * 3600); // cap 8h
  const paid = perSec() * away;
  ore += paid; earnedThisRun += paid;    // offline earnings
}
setInterval(save, 5000);
