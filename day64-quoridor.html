GAMEFROMZERO · DAY 64

🧱 Quoridor — the game whose rules contain a graph algorithm. You may place a wall anywhere, except where it would leave a player with no path at all to their goal row — so the legality of a move is not a lookup, it is a breadth-first search run twice, once per player, on the graph as it would be after the wall is placed. That single rule is what stops the game collapsing into "brick your opponent in on move three", and it means the rulebook cannot be expressed without reachability. This page implements the board as an explicit adjacency structure, runs BFS live on every one of the 128 candidate wall placements, and shows you exactly which ones are refused and why. It also implements the jump rule properly — including the diagonal case that only exists when the straight jump is blocked — and an AI that plays the standard heuristic opponentDistance − myDistance, computed with the same BFS the rules use. The no-sealing rule is tested by construction: 400 random legal games — about 59,000 plies — and the assertion that a path always existed for both players at every single ply. Pure vanilla JavaScript, one file, offline.

A rulebook you cannot write without a graph algorithm


      
Most board games have rules you can check locally. Is that square empty? Is that piece mine?
      Is the move a knight's move? All O(1) questions about a small neighbourhood.


      
Quoridor has one rule that is not local at all:


      

        
You may not place a wall that leaves any player with no path to their goal row.

      


      
To answer that you must consider the board as it would be after the move, and run a
      reachability search — for every player, not just the one you are trying to
      block. There is no local test. The rule is a graph algorithm wearing a sentence.


      
Why the rule exists

      
Without it, the game is broken in the most boring way possible: wall your opponent into a
      3×3 box and they can never finish. The no-sealing rule converts walls from a win condition into
      a tempo resource — you can lengthen someone's path, never end it. Every wall you place
      is one you no longer have, and you only get ten.


      
The board is two graphs, not one grid

      
Cells are nodes. Walls do not occupy cells — they sit between them and delete edges.
      So the natural representation is not a 9×9 array of squares with wall flags, it is:

      
blockedH[r][c]   // is the edge between (r,c) and (r+1,c) removed?
blockedV[r][c]   // is the edge between (r,c) and (r,c+1) removed?

      
A wall is 2 cells long, so placing one deletes two parallel edges. Model it
      as a single flag and the wall becomes half-length; model it as occupying squares and you will
      spend the evening converting coordinates.


      
Walls also block each other

      
Two walls may not cross, and may not overlap along their length. That is three separate
      conditions, and forgetting the crossing one is the classic bug — it lets you build a plus-sign
      out of two walls, which is not a legal shape.


      
The jump rule, and the case people skip

      
If the opponent stands in the square you want to move to, you jump over them and
      land on the far side. But if the far side is off the board or has a wall behind it, the jump
      becomes a diagonal move instead — and that diagonal is legal only in
      that case. It is not a general diagonal move.


      

        
This is the rule most implementations get subtly wrong, because the
        straightforward reading — "you can jump over" — omits that the diagonal exists as a
        consequence of the straight jump being unavailable. Allow the diagonal always and you
        have invented a different game that plays almost identically until it does not.

      


      
The AI is one line, because the BFS is already there

      
The standard Quoridor heuristic is distance(opponent) − distance(me). You are
      already computing both distances to enforce the rules, so the evaluation is free. The search on
      this page is a shallow negamax over moves and wall placements, and it plays a recognisable game
      without a single hand-tuned weight.


      
What makes this checkable

      
The no-sealing rule gives you an invariant that must hold in every reachable position, not
      just at the end: both players always have a path. So play thousands of random
      legal games and assert it after every ply. If the legality check has a hole, a random game will
      eventually walk through it — which is exactly what the button on the PLAY tab does.


    

  






  

    


      
🔨 Build it yourself


      
1. Represent edges, not squares

      
const N = 9;
// blockedH[r][c] = the edge (r,c)-(r+1,c) is gone   (a horizontal wall)
// blockedV[r][c] = the edge (r,c)-(r,c+1) is gone   (a vertical wall)
function newState(){
  return {
    pawns: [ {r:8,c:4}, {r:0,c:4} ],          // 0 = you (goal row 0), 1 = AI (goal row 8)
    blockedH: grid(N-1, N, false),
    blockedV: grid(N, N-1, false),
    walls: [],                                 // for drawing + overlap checks
    wallsLeft: [10, 10],
    turn: 0
  };
}


      
2. A wall deletes two edges

      
function applyWall(s, wall){
  const { r, c, dir } = wall;                  // anchor at the gap (r,c)
  if (dir === "H"){ s.blockedH[r][c] = true; s.blockedH[r][c+1] = true; }
  else            { s.blockedV[r][c] = true; s.blockedV[r+1][c] = true; }
  s.walls.push(wall);
}


      
3. Neighbours read the edges

      
function neighbours(s, r, c){
  const out = [];
  if (r > 0     && !s.blockedH[r-1][c]) out.push([r-1, c]);
  if (r < N-1   && !s.blockedH[r][c])   out.push([r+1, c]);
  if (c > 0     && !s.blockedV[r][c-1]) out.push([r, c-1]);
  if (c < N-1   && !s.blockedV[r][c])   out.push([r, c+1]);
  return out;
}


      
4. BFS — which is both the rule and the evaluation

      
function distanceToGoal(s, player){
  const goal = player === 0 ? 0 : N - 1;
  const start = s.pawns[player];
  const seen = grid(N, N, false);
  let frontier = [[start.r, start.c]], d = 0;
  seen[start.r][start.c] = true;
  while (frontier.length){
    const next = [];
    for (const [r, c] of frontier){
      if (r === goal) return d;
      for (const [nr, nc] of neighbours(s, r, c))
        if (!seen[nr][nc]){ seen[nr][nc] = true; next.push([nr, nc]); }
    }
    frontier = next; d++;
  }
  return Infinity;                             // sealed in
}


      
5. The legality rule, in full

      
function wallIsLegal(s, wall){
  if (s.wallsLeft[s.turn] === 0) return false;
  if (overlapsOrCrosses(s, wall)) return false;

  const test = cloneState(s);                  // never mutate the real board
  applyWall(test, wall);
  // BOTH players, not just the one you are blocking
  return distanceToGoal(test, 0) !== Infinity
      && distanceToGoal(test, 1) !== Infinity;
}

      
Two things to notice. It runs on a copy — an in-place check that forgets to
      undo itself corrupts the board on the first illegal candidate. And it checks
      both players, because a wall can seal you in just as easily.


      
6. The jump, with its conditional diagonal

      
function pawnMoves(s, player){
  const me = s.pawns[player], them = s.pawns[1 - player];
  const out = [];
  for (const [r, c] of neighbours(s, me.r, me.c)){
    if (r !== them.r || c !== them.c){ out.push([r, c]); continue; }

    // occupied: try to jump straight over, in the same direction
    const jr = r + (r - me.r), jc = c + (c - me.c);
    const straightOk = inBounds(jr, jc) && edgeOpen(s, r, c, jr, jc);
    if (straightOk){ out.push([jr, jc]); continue; }

    // ONLY when the straight jump is unavailable do the diagonals appear
    for (const [dr, dc] of neighbours(s, r, c))
      if (dr !== me.r || dc !== me.c) out.push([dr, dc]);
  }
  return out;
}


      
7. The evaluation you already computed

      
const evaluate = (s, me) =>
  distanceToGoal(s, 1 - me) - distanceToGoal(s, me);


      
8. Test the invariant, not the implementation

      
// If the legality check is correct, this can never fire.
for (let game = 0; game < 400; game++){
  const s = newState();
  while (!isOver(s) && ply < 200){
    playRandomLegalMove(s);
    assert(distanceToGoal(s, 0) !== Infinity);
    assert(distanceToGoal(s, 1) !== Infinity);
  }
}

      
Random play is a poor opponent and an excellent fuzzer. It will try wall placements no human
      would, which is precisely where a legality bug hides.
