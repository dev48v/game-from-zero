🔨 Build it yourself

    
A tower-defense game looks like it needs a whole engine — pathfinding, AI, an entity system. It needs none of that. The path is a hand-written list of waypoints. An enemy is a point that remembers which segment it's on and how far it has travelled. A tower is a point with a range and a cooldown. A projectile is a point with a target. Five plain arrays — waypoints, enemies, towers, projectiles, effects — nudged once a frame inside one requestAnimationFrame loop. About 200 lines of vanilla JavaScript on one canvas, no libraries. Copy each block in order.

    
    

      
  1. 
        
    1
    The grid, the path & which tiles you may build on
    
        
    The world is a grid of cells. The path is nothing but a list of grid corners — waypoints — that the road turns at. Walk from each waypoint to the next, one cell at a time, and mark those cells as "road" in a set. A tower may be placed on any cell that is on the board, is not road, and is not already occupied. That single set is the entire map.
    
        
    const COLS = 20, ROWS = 13, CELL = 40;           // 800 x 520 board
const WPC = [[0,2],[4,2],[4,10],[9,10],[9,4],    // path corners (col,row)
             [14,4],[14,10],[17,10],[17,2],[19,2]];
const center = (c,r) => ({ x:c*CELL+CELL/2, y:r*CELL+CELL/2 });
const WP = WPC.map(([c,r]) => center(c,r));       // waypoints in pixels

const road = new Set();                          // which cells are path
for (let i = 0; i < WPC.length-1; i++){
  let [c,r] = WPC[i]; const [tc,tr] = WPC[i+1];
  const dc = Math.sign(tc-c), dr = Math.sign(tr-r);
  road.add(c+','+r);
  while (c !== tc || r !== tr){ c += dc; r += dr; road.add(c+','+r); }
}
const buildable = (c,r) =>
  c>=0 && r>=0 && c<COLS && r<ROWS && !road.has(c+','+r) && !occupied.has(c+','+r);
    
      
    2. 

      
  2. 
        
    2
    An enemy walks the waypoints — lerp toward the next corner
    
        
    An enemy is a point that knows which segment of the path it is on. Each frame we give it a budget of movement — speed × slow × dt pixels — and spend it walking straight toward the next waypoint. If it reaches that corner with budget left, it advances a segment and keeps going, so it banks corners smoothly. We also add every pixel it moves to dist — its total progress — which the towers use to pick a target. Run off the last waypoint and the creep has leaked.
    
        
    function moveEnemy(e, dt){
  let budget = e.speed * e.slow * dt;
  while (budget > 0 && e.seg < WP.length-1){
    const t = WP[e.seg+1];
    const dx = t.x-e.x, dy = t.y-e.y, d = Math.hypot(dx,dy);
    if (d <= budget){                       // reached this corner
      e.x = t.x; e.y = t.y; budget -= d; e.dist += d; e.seg++;
    } else {                                // move partway along the segment
      e.x += dx/d*budget; e.y += dy/d*budget; e.dist += budget; budget = 0;
    }
  }
  if (e.seg >= WP.length-1) e.leaked = true; // reached the base
}

  3. 
        
    3
    A tower auto-targets — range check + "first" selection
    
        
    A tower does two things a frame: pick a target and, if ready, shoot. Picking is a loop: of all enemies whose distance is inside the tower's range, keep the one with the greatest dist — the creep furthest along the path, closest to your base. That is the classic "first" targeting most TD players want (swap the comparison for nearest, lowest-HP, or strongest). A cooldown timer cd counts down every frame; when it hits zero and there's a target, fire and reset it.
    
        
    function updateTower(tw, dt){
  tw.cd -= dt;
  let target = null, best = -1;
  for (const e of enemies){
    if (e.dead || e.leaked) continue;
    if (Math.hypot(e.x-tw.x, e.y-tw.y) <= tw.range && e.dist > best){
      best = e.dist; target = e;            // "first" = furthest along the path
    }
  }
  if (target){
    tw.angle = Math.atan2(target.y-tw.y, target.x-tw.x);   // swivel the barrel
    if (tw.cd <= 0){ fire(tw, target); tw.cd = tw.fireRate; }
  }
}

  4. 
        
    4
    Projectiles home to the target, then deal damage on contact
    
        
    Firing pushes a projectile that remembers its target object, not a fixed point — so it curves to follow a moving creep. Each frame it steps toward the target; when the gap closes to within the enemy's radius it's a hit. A hit subtracts damage; a cannon shell also damages every enemy inside its splash radius; a frost bolt sets the target's slow factor and a timer. If the target dies mid-flight the projectile simply fizzles.
    
        
    function fire(tw, target){
  projectiles.push({ x:tw.x, y:tw.y, target, speed:tw.projSpeed,
                     damage:tw.damage, splash:tw.splash, slowF:tw.slowF });
}
function updateProjectile(p, dt){
  const t = p.target;
  if (!t || t.dead || t.leaked){ p.dead = true; return; }   // target gone
  const dx = t.x-p.x, dy = t.y-p.y, d = Math.hypot(dx,dy) || 1e-6;
  if (d <= p.speed*dt + t.r){                                // contact
    hurt(t, p.damage);
    if (p.splash) for (const e of enemies)                   // cannon splash
      if (e !== t && Math.hypot(e.x-t.x,e.y-t.y) <= p.splash) hurt(e, p.damage*0.6);
    if (p.slowF < 1){ t.slow = Math.min(t.slow, p.slowF); t.slowT = 1.4; } // frost
    p.dead = true;
  } else { p.x += dx/d*p.speed*dt; p.y += dy/d*p.speed*dt; }
}

  5. 
        
    5
    The economy — a kill pays gold, gold buys towers
    
        
    Damage is a subtraction; death is the payout. When an enemy's hit-points cross zero it's flagged dead and its reward is added to your gold. Building spends gold: only if you can afford the tower and the tile is buildable does the purchase go through — deduct the cost, drop the tower, mark the cell occupied. Upgrading and selling are the same ledger in reverse. That loop — kills fund towers, towers make kills — is the whole game of it.
    
        
    function hurt(e, dmg){
  if (e.dead) return;
  e.hp -= dmg;
  if (e.hp <= 0){ e.dead = true; gold += e.reward; score += e.reward; } // payout
}
function buy(type, c, r){
  const def = TOWER_DEFS[type];
  if (gold < def.cost || !buildable(c,r)) return false;               // gate
  gold -= def.cost;
  towers.push({ type, ...def, x:c*CELL+CELL/2, y:r*CELL+CELL/2,
                col:c, row:r, level:1, cd:0, angle:0, invested:def.cost });
  occupied.add(c+','+r);
  return true;
}

    6
    Waves escalate — a spawn queue that grows and hardens
    
        
    A wave is just a list of enemies to release, one every spawnInterval seconds. Wave N makes a longer list, mixes in fast runners and armoured tanks, drops a boss every fifth wave, and multiplies every creep's hit-points by an exponential scale so later waves genuinely bite. When the queue is empty and the last creep is gone, the wave is cleared, you bank a bonus, and the next one waits for your click.
    
        
    function buildWave(n){
  const scale = Math.pow(1.14, n-1), list = [];        // exponential difficulty
  const count = 6 + Math.floor(n*1.5);
  for (let i = 0; i < count; i++){
    let type = 'grunt';
    if (n >= 2 && i%3 === 1) type = 'fast';
    if (n >= 3 && i%5 === 4) type = 'tank';
    list.push({ type, scale });
  }
  if (n % 5 === 0) list.push({ type:'boss', scale });  // boss every 5th wave
  return list;
}
function spawn(item){
  const d = ENEMY_DEFS[item.type], hp = Math.round(d.hp*item.scale);
  enemies.push({ ...d, x:WP[0].x, y:WP[0].y, seg:0, dist:0,
                 hp, maxHp:hp, slow:1, slowT:0, dead:false, leaked:false });
}

    7
    Lives, game-over & the loop that ties it together
    
        
    One step(dt) runs the whole simulation in order: spawn from the queue, move the enemies (a leak costs a life and, at zero, ends the run), aim and fire every tower, advance the projectiles, then sweep out everything flagged dead. The requestAnimationFrame loop measures real elapsed time, runs step once (or twice at ×2 speed), and redraws. Nothing here is an engine — it's five arrays and a clock.
    
        
    function step(dt){
  if (waveActive) spawnFromQueue(dt);
  for (const e of enemies){
    if (e.slowT > 0 && (e.slowT -= dt) <= 0) e.slow = 1;    // frost wears off
    moveEnemy(e, dt);
    if (e.leaked){ e.dead = true; if ((lives -= e.leakCost) <= 0) over(); }
  }
  for (const tw of towers)       updateTower(tw, dt);
  for (const p  of projectiles)  updateProjectile(p, dt);
  enemies     = enemies.filter(e => !e.dead);              // sweep the dead
  projectiles = projectiles.filter(p => !p.dead);
  if (waveActive && !spawnQueue.length && !enemies.length) waveCleared();
}
let last = performance.now();
function loop(now){
  let dt = Math.min((now-last)/1000, 0.033); last = now;
  if (running && !paused) for (let s = 0; s < speed; s++) step(dt);
  draw();
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);
