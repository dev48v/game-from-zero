🔨 Build it yourself

    
Kaboom is a canvas game with almost no moving parts: a bomber that patrols left-to-right, an array of bombs that fall under gravity, and one paddle you steer. A single requestAnimationFrame loop advances every object by real elapsed seconds, a rectangle-overlap test at the bucket rim decides catch-or-miss, and clearing a wave just nudges a few difficulty numbers. About 130 lines of vanilla JavaScript, no libraries. Copy each block in order.

    
    

      
  1. 
        
    1
    The whole game is three things on a canvas
    
        
    There is no world and no sprites — just a bomber (one point that slides across the top), an array of bombs (each a point with a downward velocity), and a paddle (the bucket stack you control). Everything on screen is redrawn from these plain variables every frame, plus a handful of counters for score, wave, and how many buckets you have left.
    
        
    const cv  = document.getElementById("game");
const ctx = cv.getContext("2d");
const W = cv.width, H = cv.height;      // 600 x 640

const RIM_Y    = H - 120;   // top of the bucket stack = the catch line
const GROUND_Y = H - 46;    // the floor a missed bomb explodes on

let paddle, bomber, bombs, wave, buckets, score;

function reset(){
  paddle  = { x: W/2, hw: 52, target: W/2 };  // hw = half-width
  bomber  = { x: W/2, y: 34, w: 40, vx: 150, dir: 1 };
  bombs   = [];        // {x, y, vy, r}
  wave    = 1;
  buckets = 3;         // three buckets = three lives
  score   = 0;
}

    2
    The game loop moves everything by real time
    
        
    A canvas game is a loop: on every animation frame we measure dt — the real seconds since the last frame — then update every object by that amount and redraw. Multiplying speeds by elapsed seconds makes the game run the same on a 60fps or a 144fps screen. We clamp dt so a hidden tab or a stutter can't teleport a bomb straight through the buckets.
    
        
    let last = performance.now();

function loop(now){
  let dt = (now - last) / 1000;   // real seconds elapsed
  last = now;
  if (dt > 0.05) dt = 0.05;       // clamp big gaps (tab switch / lag)
  update(dt);                     // advance bomber + bombs + paddle
  draw();                         // repaint the whole canvas
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

    3
    The bomber patrols and bounces off the walls
    
        
    The Mad Bomber is a single x-coordinate moving at vx in a direction (+1 or -1). Each frame we add vx · dir · dt. When he reaches either edge we pin him to the wall and flip dir, so he ping-pongs across the top forever. Faster waves just raise vx.
    
        
    function moveBomber(dt){
  bomber.x += bomber.vx * bomber.dir * dt;
  if (bomber.x < bomber.w/2){         // hit the left wall
    bomber.x = bomber.w/2; bomber.dir = 1;
  }
  if (bomber.x > W - bomber.w/2){     // hit the right wall
    bomber.x = W - bomber.w/2; bomber.dir = -1;
  }
}

  4. 
        
    4
    Dropping bombs on a timer
    
        
    Bombs are spawned by a stopwatch, not by frames — a per-frame spawn would flood the screen at high frame rates. We accumulate dt into dropTimer; once it passes dropInterval we reset it and push a new bomb at the bomber's current position. Shrinking dropInterval in later waves makes the bombs rain faster.
    
        
    let dropTimer = 0, dropInterval = 1.0;

function maybeDrop(dt){
  dropTimer += dt;
  if (dropTimer >= dropInterval){
    dropTimer = 0;
    bombs.push({ x: bomber.x, y: bomber.y + 18,
                 vy: initVy, r: 11 });   // spawn under the bomber
  }
}

    5
    Real physics — bombs fall under gravity
    
        
    A bomb does not drop at a constant speed; it accelerates, exactly like a real falling object. Each frame gravity adds to its downward velocity (vy += g · dt), then that velocity moves it down (y += vy · dt). This is Euler integration — the same two lines every physics engine uses. Because the bomb starts slow and speeds up, catching it late is far harder than catching it early, which is the whole tension of the game.
    
        
    let gravity = 330;     // px per second, per second (acceleration)

function fall(b, dt){
  b.vy += gravity * dt;   // velocity gains speed each frame
  b.y  += b.vy   * dt;    // position moves by the new velocity
}
// start slow (initVy small) -> ends fast. That is gravity.

    6
    Steering the buckets — keyboard or mouse
    
        
    Two control schemes share one paddle. The keyboard moves it at a fixed speed while a key is held (x ± speed · dt). The mouse sets a target x and the paddle eases toward it each frame, so it feels smooth instead of teleporting. Either way we clamp x so the bucket stack can never leave the arena. The mouse target only wins when no arrow key is down.
    
        
    function movePaddle(dt){
  const SPEED = 460;
  if (keys.left)  paddle.x -= SPEED * dt;
  if (keys.right) paddle.x += SPEED * dt;
  if (!keys.left && !keys.right)                 // else follow the mouse
    paddle.x += (paddle.target - paddle.x) * Math.min(1, dt*18);

  paddle.x = Math.max(paddle.hw,                 // clamp inside the walls
             Math.min(W - paddle.hw, paddle.x));
}

    Catch detection — a rectangle-overlap test
    
        
    Collision here is simple because the buckets never move vertically. A bomb is caught the moment its centre drops past the bucket rim (y ≥ RIM_Y) while its x sits within the paddle's half-width. If it drops all the way to the floor (y − r > GROUND_Y) without ever lining up, it's a miss. We walk the bomb array backwards so we can splice out caught/missed bombs safely mid-loop.
    
        
    for (let i = bombs.length - 1; i >= 0; i--){
  const b = bombs[i];
  fall(b, dt);

  if (b.y >= RIM_Y && Math.abs(b.x - paddle.x) <= paddle.hw + b.r){
    bombs.splice(i, 1); onCatch();      // rim + x line up -> caught
  } else if (b.y - b.r > GROUND_Y){
    bombs.splice(i, 1); onMiss(); break; // reached the floor -> miss
  }
}

    8
    A miss explodes and clears the sky
    
        
    One dropped bomb sets off every bomb on screen — the classic Kaboom blast — so a miss empties the whole array and costs you a bucket. A short negative timer gives you a beat to breathe before bombs resume. When the last bucket is gone the game ends and the best score is saved. This all-or-nothing punishment is why the game gets frantic.
    
        
    function onMiss(){
  buckets--;              // lose a bucket (a life)
  bombs = [];             // the blast wipes the screen
  dropTimer = -0.6;       // brief pause before bombs return
  if (buckets <= 0){
    state = "over";
    if (score > hi){ hi = score; saveHi(); }
  }
}

    9
    Waves — the difficulty ramp
    
        
    Catch enough bombs and the wave clears: the bomber flies faster, gravity gets stronger, bombs drop more often, and each catch is worth more (up to 8 points). One function reads the wave number and sets all four knobs, so difficulty is data, not scattered ifs. This is the arcade heartbeat — every clear makes the next one harder and more rewarding.
    
        
    function applyWave(){
  ppb          = Math.min(wave, 8);                  // points per catch
  groupSize    = 8 + wave * 2;                       // catches to clear
  bomber.vx    = 130 + wave * 22;                    // patrol speed
  gravity      = 300 + wave * 60;                    // stronger pull
  initVy       = 30  + wave * 10;                    // faster start
  dropInterval = Math.max(0.34, 1.05 - wave * 0.07); // rain faster
}
function onCatch(){
  score += ppb; caughtInGroup++;
  if (caughtInGroup >= groupSize){ wave++; caughtInGroup = 0; applyWave(); }
}

    Lives, bonus buckets, and drawing it all
    
        
    Every 1,000 points earns a bucket back (capped at three), rewarding a long clean run. Drawing is just repainting: clear the canvas, fill the sky and ground, stamp the bomber and each bomb with an emoji via fillText, and draw one trapezoid per remaining bucket at the paddle's x. A state flag (ready / playing / over) decides whether to run physics or show an overlay.
    
        
    function draw(){
  ctx.clearRect(0,0,W,H);
  paintSky(); paintGround();
  ctx.textAlign = "center"; ctx.textBaseline = "middle";
  ctx.font = "30px serif"; ctx.fillText("😈", bomber.x, bomber.y);
  ctx.font = "22px serif";
  bombs.forEach(b => ctx.fillText("💣", b.x, b.y));
  for (let i = 0; i < buckets; i++) drawBucket(paddle.x, i);  // one per life
  if (state !== "playing") drawOverlay();
}
