🔨 Build it yourself

    
Yahtzee looks like thirteen unrelated scoring rules, but they all read from the same one-line helper: a counts[1..6] array of how many of each face you rolled. Once you have that, "sum of the 5s" and "is this a full house?" are each one expression. The rest is a three-roll turn, a hold-and-reroll toggle, one-box-per-turn bookkeeping, and a grand total with a single bonus test. About 180 lines of vanilla JavaScript, no libraries, no canvas. Copy each block in order.

    
    

      
  1. 
        
    1
    The whole game is five ints and a scorecard object
    
        
    There is no board and no dice objects — the state is tiny. Five integers hold the dice faces, five booleans say which ones you're keeping, a counter tracks how many of your three rolls remain, and the scorecard is a plain object mapping each of the thirteen box names to a number once you've scored it or null while it's still open. Everything else in the game is a function that reads these few variables.
    
        
    const CATS = ["ones","twos","threes","fours","fives","sixes",
  "threeKind","fourKind","fullHouse","smallStraight",
  "largeStraight","yahtzee","chance"];        // the 13 boxes

let dice     = [null,null,null,null,null];   // the five faces, 1..6
let held     = [false,false,false,false,false]; // which you keep on re-roll
let rollsLeft = 3;                            // three throws per turn
let hasRolled = false;                        // rolled at least once this turn?
let turn      = 1;                            // 1 .. 13
let phase     = "play";                       // play | over
let scores    = {};                           // box → number, or absent = open
CATS.forEach(k => scores[k] = null);

  2. 
        
    2
    Roll — but only the dice you didn't hold
    
        
    A roll re-throws only the loose dice: for each of the five, if it isn't held, replace it with a fresh 1–6. Held dice keep their face. Each roll costs one of your three, and after the first roll of a turn you're allowed to toggle holds. That single if (!held[i]) is the entire "keep some, re-roll the rest" mechanic that the whole gamble of Yahtzee rests on.
    
        
    function roll(){
  if (phase !== "play" || rollsLeft <= 0) return;
  for (let i = 0; i < 5; i++)
    if (!held[i]) dice[i] = 1 + Math.floor(Math.random() * 6); // loose ones only
  rollsLeft--;
  hasRolled = true;
  render();
}
function toggleHold(i){                         // click a die between rolls
  if (phase !== "play" || !hasRolled || rollsLeft <= 0) return;
  held[i] = !held[i];
  render();
}

    3
    One helper to rule them all — counts of each face
    
        
    This is the trick that makes thirteen rules feel like one. Walk the five dice once and tally how many showed each face into a seven-slot array (index 0 unused, 1–6 the faces). From that single histogram every category is answerable: "three of a kind" is "does any count reach 3?", "sixes" is "count[6] × 6", a straight is a run of consecutive non-zero counts. Compute it once per hand and every score falls out of it.
    
        
    function counts(d){                             // histogram of the faces
  const c = [0,0,0,0,0,0,0];                    // c[1]..c[6]
  for (const x of d) c[x]++;
  return c;
}
function sum(d){ return d.reduce((a,b) => a + b, 0); }  // total of all five

// e.g. dice [5,2,5,5,2]  →  counts = [0,0,2,0,0,3,0]
//   c[5] = 3  (three fives),  c[2] = 2  (two twos)

    The upper section — and the +35 bonus at 63
    
        
    The six upper boxes are the simplest scores in the game: the "fives" box is worth the count of 5s times 5, and so on for every face. The famous bonus rewards spreading your luck: if the six upper boxes together reach 63 or more you get a flat +35. Why 63? Because 63 is exactly three of each face — three 1s + three 2s + … + three 6s = 3 × (1+2+3+4+5+6) = 3 × 21 = 63. Averaging three-of-a-kind across the top half is the bonus's break-even line, and the whole bonus is one ≥ 63 comparison.
    
        
    const FACE = { ones:1, twos:2, threes:3, fours:4, fives:5, sixes:6 };

function upperScore(cat, c){ return c[FACE[cat]] * FACE[cat]; } // count × face

function upperSubtotal(){                       // the six upper boxes so far
  return ["ones","twos","threes","fours","fives","sixes"]
    .reduce((a, k) => a + (scores[k] || 0), 0);
}
function upperBonus(){
  return upperSubtotal() >= 63 ? 35 : 0;         // 63 = three of every face
}

    5
    The lower section — every rule reads the histogram
    
        
    The seven lower boxes are combinations, and each is one question about counts. Three- and four-of-a-kind: if any face count reaches 3 (or 4), score the sum of all five dice, else zero. Full house: some face appears exactly 3 times and another exactly 2 → a fixed 25. Straights are a longest-run scan over the six counts — four in a row is a small straight (30), five in a row a large straight (40). Yahtzee is any count hitting 5 → 50. Chance is the escape hatch: just the sum, always.
    
        
    function longestRun(c){                          // consecutive present faces
  let run = 0, best = 0;
  for (let f = 1; f <= 6; f++){ run = c[f] ? run + 1 : 0; best = Math.max(best, run); }
  return best;
}
function scoreFor(cat, d){
  const c = counts(d), total = sum(d);
  if (cat in FACE)           return c[FACE[cat]] * FACE[cat];
  if (cat === "threeKind")   return c.some(n => n >= 3) ? total : 0;
  if (cat === "fourKind")    return c.some(n => n >= 4) ? total : 0;
  if (cat === "fullHouse")   return c.includes(3) && c.includes(2) ? 25 : 0;
  if (cat === "smallStraight") return longestRun(c) >= 4 ? 30 : 0;
  if (cat === "largeStraight") return longestRun(c) >= 5 ? 40 : 0;
  if (cat === "yahtzee")     return c.some(n => n === 5) ? 50 : 0;
  if (cat === "chance")      return total;
}

    Live preview + spend exactly one box a turn
    
        
    Because scoreFor is pure — dice in, number out — you can show a live preview: for every box that's still open, run it against the current dice and print the result in green. Choosing a box commits that number. The one iron rule of Yahtzee is enforced in three lines: you may only score an open box, and doing so writes the number, ends the turn, and resets the dice — so you always spend exactly one box per turn, even if that means banking a zero.
    
        
    function chooseCategory(cat){
  if (phase !== "play" || !hasRolled || scores[cat] !== null) return; // open only
  scores[cat] = scoreFor(cat, dice);            // commit the previewed number
  if (CATS.every(k => scores[k] !== null)){ phase = "over"; render(); return; }
  turn++;                                        // next turn: fresh three rolls
  rollsLeft = 3; hasRolled = false;
  held = [false,false,false,false,false];
  dice = [null,null,null,null,null];
  render();
}
// preview for an open box = scoreFor(cat, dice), shown in green until committed

    7
    Thirteen turns, then the grand total
    
        
    There are exactly as many turns as boxes: thirteen. When the last open box is filled the game is over. The grand total is three sums bolted together — the upper subtotal, plus the +35 bonus if it earned it, plus every lower box. Because unfilled boxes are null they simply count as zero in the running total, so the same total function works live during the game and as the final score at the end.
    
        
    function lowerTotal(){
  return ["threeKind","fourKind","fullHouse","smallStraight",
          "largeStraight","yahtzee","chance"]
    .reduce((a, k) => a + (scores[k] || 0), 0);
}
function grandTotal(){
  return upperSubtotal() + upperBonus() + lowerTotal();
}
// game ends the moment CATS.every(k => scores[k] !== null) — 13 boxes, 13 turns
