GameFromZero · Day 43

🏍️ Tron Light-Cycles — Race Your Cycle Around a Walled Grid Arena Against a CPU Rider, Each of You Laying a Solid Wall of Light Behind You Every Cell You Cross; Steer With the Arrow Keys, Never Reverse Into Your Own Trail, and Force the Enemy to Smash Into a Wall, Your Trail, or Its Own — First Rider to Crash Loses the Round, First to Five Wins the Match

Two cycles, one shrinking arena. Outlast the machine.

A light-cycle duel is the purest survival game there is. The arena is nothing but a grid of cells, and each rider is a single moving point that can never stop and never slow down — one cell every tick, forever. Wherever a cycle has been turns into a solid wall of light, so the board fills up as the round goes on and the free space collapses. Touch anything — the outer wall, your own trail, or the enemy’s — and you crash. You steer with the arrow keys (or WASD), turning 90° at a time; the one move you are never allowed is a straight reverse into the wall you just laid. The CPU rider isn’t scripted to follow a path — every tick it looks ahead, flood-fills the open space each of its turns would lead into, and drives toward the roomiest side so it doesn’t seal itself into a shrinking pocket. Bait it into a corner, cut off its escape, and let its own greed trap it. First crash loses the round; first to five takes the match.

There is no physics engine and no sprites — the whole game is a 2-D array where each cell is 0 (empty), 1 (your trail) or 2 (the CPU’s). A rider is just a (row, col) position plus a (row, col) direction vector; every tick each rider’s next cell is pos + dir. Collision is one line — that next cell is fatal if it is off the board or already non-zero. The CPU’s “intelligence” is a bounded flood-fill: for each of its three legal turns it counts how many empty cells are reachable, and steers toward the largest. All vanilla JavaScript on one canvas, offline, one file.

🔨 Build it yourself

    
No engine, no sprite sheet — a Tron duel is a 2-D array of cells, two moving points, and one collision test. Everything runs on a fixed tick: read the player’s buffered turn, let the CPU pick a turn by looking ahead, compute both next cells as pos + dir, and check each against the board — off the edge or onto any trail means a crash. The only clever part is the CPU: a bounded flood-fill that counts the open room behind each of its three legal turns so it drives into space instead of trapping itself. About 130 lines of vanilla JavaScript on one canvas, no libraries. Copy each block in order.

    The arena is a grid of cells
    
        
    The whole game state is one 2-D array. Every cell holds 0 for empty, 1 for your trail, or 2 for the CPU’s. The canvas is only a view of this array — the truth lives in occ. We size the canvas to the grid so one array cell maps to one square of CELL pixels, and clear the array to all-zero at the start of every round.
    
        
    const CELL = 12, COLS = 48, ROWS = 30;   // arena is 48 x 30 cells

let occ;   // occ[r][c] = 0 empty | 1 you | 2 cpu

function emptyGrid(){
  return Array.from({length:ROWS}, () => new Array(COLS).fill(0));
}

canvas.width  = COLS * CELL;   // one cell = CELL px
canvas.height = ROWS * CELL;

  2. 
        
    2
    A cycle is a point plus a direction
    
        
    Each rider is just a cell position (r, c) and a step vector (dr, dc) — the direction it will move next tick. They spawn on opposite sides facing each other: you on the left heading east, the CPU on the right heading west. We immediately mark each spawn cell occupied, because a cycle’s very first cell is already a wall the other rider can crash into.
    
        
    let player, ai;

function resetArena(){
  occ = emptyGrid();
  player = { r: ROWS>>1, c: 9,        dr:0, dc: 1, next:null }; // heading E
  ai     = { r: ROWS>>1, c: COLS-10,  dr:0, dc:-1 };            // heading W
  occ[player.r][player.c] = 1;
  occ[ai.r][ai.c]         = 2;
}

    3
    The tick is the heartbeat
    
        
    A cycle never stops, so the game is driven by a fixed-interval tick. Every TICK_MS milliseconds the whole world advances exactly one cell. That single step() call is where turns are applied, the CPU decides, both riders move, and crashes are detected. Slower ticks = an easier, more readable game; faster = frantic.
    
        
    const TICK_MS = 70;
let tickId = null;

function startRunning(){
  clearInterval(tickId);
  tickId = setInterval(step, TICK_MS);   // one cell per tick, forever
}

    4
    Steering — turn, but never reverse
    
        
    Arrow keys don’t move you directly; they buffer a desired direction that the next tick applies. Buffering avoids two turns inside one tick. The one illegal move is a straight reverse — flipping 180° would drive you instantly into the trail cell right behind you, so we reject any direction that is the negative of the current heading.
    
        
    const KEYS = { ArrowUp:[-1,0], ArrowDown:[1,0], ArrowLeft:[0,-1], ArrowRight:[0,1],
               w:[-1,0], s:[1,0], a:[0,-1], d:[0,1] };

function setDir(dir){
  const [cr, cc] = [player.dr, player.dc];
  if (dir[0] === -cr && dir[1] === -cc) return;   // no 180° reverse
  player.next = dir;                              // applied at next tick
}

    5
    Collision detection is one line
    
        
    This is the whole rulebook. A candidate next cell kills its rider if it falls outside the grid or if it is already non-zero — meaning any wall at all: the arena edge, your own light-trail, or the enemy’s. Because both trails live in the same array with the same “solid” meaning, one test covers every way to die.
    
        
    function crashes(cell){
  return cell.r < 0 || cell.r >= ROWS ||
         cell.c < 0 || cell.c >= COLS ||
         occ[cell.r][cell.c] !== 0;     // any trail = solid wall
}

  6. 
        
    6
    One tick, resolved in order
    
        
    The tick applies your buffered turn, lets the CPU choose, then computes both next cells and judges them before anyone moves. If both aim at the same cell it’s a head-on tie; if both would crash it’s a tie; otherwise whoever crashes loses. Only when both cells are safe do we stamp the trails and advance the heads. Checking first, moving second, is what makes simultaneous outcomes fair.
    
        
    function step(){
  if (player.next){ [player.dr, player.dc] = player.next; player.next = null; }
  aiChoose();                                     // CPU sets its own dir

  const pN = { r: player.r + player.dr, c: player.c + player.dc };
  const aN = { r: ai.r     + ai.dr,     c: ai.c     + ai.dc     };

  const headOn = pN.r === aN.r && pN.c === aN.c;
  const pDead = crashes(pN), aDead = crashes(aN);

  if (headOn || (pDead && aDead)) return endRound("tie");
  if (pDead) return endRound("ai");               // you crashed
  if (aDead) return endRound("player");           // cpu crashed

  occ[pN.r][pN.c] = 1; player.r = pN.r; player.c = pN.c;
  occ[aN.r][aN.c] = 2; ai.r     = aN.r; ai.c     = aN.c;
  draw();
}

  7. 
        
    7
    The CPU has three choices
    
        
    Just like you, the CPU can never reverse, so from its current heading it has exactly three options: keep straight, turn left, or turn right. A 90° turn is a swap of the vector’s components with one sign flipped — left = (-dc, dr) and right = (dc, -dr). These three vectors are the entire set of moves the AI ever gets to consider.
    
        
    function turns(dr, dc){
  return [
    [dr, dc],      // straight
    [-dc, dr],     // turn left  (90° rotate)
    [dc, -dr]      // turn right (90° rotate)
  ];
}

    8
    Look-ahead: measure the open space
    
        
    A naive bot that just avoids the next wall will happily drive into a dead-end pocket and bury itself. The fix is to look further: from a candidate cell, run a bounded flood-fill — a breadth-first sweep — that counts how many empty cells are reachable. That number is “how much room is on this side.” We cap the count so it stays cheap; we only need to compare options, not map the whole board.
    
        
    function freeSpace(r, c, cap){
  if (crashes({r, c})) return 0;                  // dead on arrival
  const seen = new Set([r * COLS + c]);
  const queue = [[r, c]];
  let count = 0;
  while (queue.length && count < cap){
    const [cr, cc] = queue.shift(); count++;
    for (const [dr, dc] of [[1,0],[-1,0],[0,1],[0,-1]]){
      const nr = cr+dr, nc = cc+dc, key = nr*COLS+nc;
      if (nr<0||nr>=ROWS||nc<0||nc>=COLS) continue;
      if (occ[nr][nc] !== 0 || seen.has(key)) continue;
      seen.add(key); queue.push([nr, nc]);
    }
  }
  return count;                                   // reachable room, capped
}

    9
    The CPU picks the roomiest turn
    
        
    Now the decision is easy: score each of the three legal turns by the open space it leads into, nudge the straight option slightly so the bot doesn’t jitter, add a hair of randomness to break ties, and steer toward the best. If every turn is instant death it just holds course and crashes — which is exactly when you have trapped it. This greedy “drive toward the most space” rule is a genuinely tough opponent.
    
        
    function aiChoose(){
  let best = null, bestScore = -1;
  for (const [ndr, ndc] of turns(ai.dr, ai.dc)){
    const nr = ai.r + ndr, nc = ai.c + ndc;
    if (crashes({r:nr, c:nc})) continue;          // skip lethal turns
    let score = freeSpace(nr, nc, 140);
    if (ndr === ai.dr && ndc === ai.dc) score += 2;  // prefer straight
    score += Math.random() * 0.5;                    // break ties
    if (score > bestScore){ bestScore = score; best = [ndr, ndc]; }
  }
  if (best){ ai.dr = best[0]; ai.dc = best[1]; }  // else hold course & die
}

    Rounds, score, and the win
    
        
    When step() reports a crash, the round ends: stop the tick, award the point (a tie awards none), and update the score. First rider to WIN_TARGET takes the match and the board waits for New game; otherwise the arena wipes and the next round auto-starts after a short pause. Drawing is pure state — repaint the dark grid, fill every trail cell in its owner’s colour, and glow the two heads.
    
        
    const WIN_TARGET = 5;
let pScore = 0, aScore = 0, round = 1;

function endRound(who){
  clearInterval(tickId);
  if (who === "player") pScore++;
  else if (who === "ai") aScore++;
  updateHUD();
  if (pScore >= WIN_TARGET || aScore >= WIN_TARGET){
    setStatus(pScore > aScore ? "🏆 You win the match!" : "🤖 CPU wins the match.");
    return;                                       // wait for New game
  }
  setTimeout(nextRound, 1400);                    // wipe + next round
}
