Kakuro — the arithmetic is the easy part, and a solver that only does arithmetic never finishes.

Cross-sums, with every digit in a run distinct

Kakuro is a crossword made of sums. Each run of white cells carries a clue: the digits in it must add to that total, they are drawn from 1 to 9, and no digit repeats inside a run. That last rule is what makes it a puzzle rather than a worksheet — it turns each clue into a question about which sets of distinct digits hit a total, not merely how to reach it.

9 to the power of the cell count

The combination table is the whole game

Before touching a board, ask a smaller question: how many sets of k distinct digits from 1–9 sum to s? Most of Kakuro's famous deductions fall straight out of this table, and they are not arithmetic tricks — they are places where the answer is exactly one set.

What the clue tells you before you write anything

Every clue narrows the digits that can appear in its run, whatever else is on the board. Intersect a row's candidates with a column's and most cells collapse immediately.

Why the sum alone is not a constraint worth having

A solver that checks only "do the digits in this run add to the clue" can verify a finished board, and that is all it can do. It cannot prune, because a partially filled run tells it almost nothing: any running total below the clue is still potentially fine.

The constraint that actually prunes is the candidate set: the union of all digits that appear in any valid combination for that clue and length. A digit outside that union can be rejected the moment it is proposed, before any arithmetic happens.

The bound that fires earliest

Partway through a run you know the digits placed and how many cells remain. The remaining cells must take distinct unused digits, so the rest of the sum is boxed in: at least the smallest available digits, at most the largest. If the clue's remainder falls outside that window, the branch is dead immediately.
