The board is stored as 40 walls, not 16 squares — 20 horizontal, 20 vertical — and a box is nothing but four indices into that list. Everything else falls out of two counts: how many of a box's four walls are drawn, and how many boxes a wall would close. Draw the fourth wall and the box is yours and you move again; that one clause is what makes late-game sacrifices cascade. 🔨 Build it yourself

    
Dots and Boxes looks like a toy until you try to write an opponent for it, and then it turns out to be one of the most beautiful small games there is. The trick is to stop thinking in squares. The whole board is a flat array of walls; a box is four indices into that array; and every rule in the game is one of two counts — how many of a box's four walls are drawn, and how many boxes a wall would close. Get those two right and the extra-turn rule, the safe/sacrifice split, chains, loops, the double-cross and an exact endgame solver all follow in a few lines each. Below is the whole thing in eight blocks. Copy them in order.

    
    

      
  1. 
        
    1
    Number every wall, then link walls to boxes both ways
    
        
    A 4×4 board of boxes has 5×5 dots and exactly 40 walls: 20 horizontal (5 rows × 4) and 20 vertical (4 rows × 5). Give them ids 0…39 — horizontals first, then verticals — and the entire game state becomes one Uint8Array(40) of drawn/not. Then precompute two tables once: BOX_EDGES[b], the four wall ids of box b, and EDGE_BOXES[id], the one or two boxes a wall touches. Border walls touch one box, interior walls touch two — which is precisely why one wall can close two boxes at once.
    
        
    const BR = 4, BC = 4;                       // boxes down, boxes across
const HCOLS = BC, HROWS = BR + 1;           // 4 x 5 = 20 horizontal walls
const VCOLS = BC + 1, VROWS = BR;           // 5 x 4 = 20 vertical walls
const H_COUNT = HROWS * HCOLS;              // ids 0..19  = horizontal
const EDGES   = H_COUNT + VROWS * VCOLS;    // ids 20..39 = vertical  -> 40 total
const NB = BR * BC;                         // 16 boxes, b = r*BC + c

const BOX_EDGES = [];                       // box -> [top, bottom, left, right]
for (let r = 0; r < BR; r++) for (let c = 0; c < BC; c++)
  BOX_EDGES[r*BC+c] = [ r*HCOLS+c, (r+1)*HCOLS+c,
                        H_COUNT + r*VCOLS + c, H_COUNT + r*VCOLS + c + 1 ];

const EDGE_BOXES = [];                      // wall -> the 1 or 2 boxes it touches
for (let id = 0; id < EDGES; id++){
  const out = [];
  if (id < H_COUNT){ const r = (id/HCOLS)|0, c = id%HCOLS;
    if (r > 0)  out.push((r-1)*BC + c);     // box above
    if (r < BR) out.push(r*BC + c);         // box below
  } else { const k = id - H_COUNT, r = (k/VCOLS)|0, c = k%VCOLS;
    if (c > 0)  out.push(r*BC + c - 1);     // box to the left
    if (c < BC) out.push(r*BC + c);         // box to the right
  }
  EDGE_BOXES[id] = out;
}

    Drawing a wall, and claiming whatever it closes
    
        
    The state is three small arrays: which walls are drawn, who owns each box, and the two scores. Playing a wall is three lines — mark it drawn, look at the one or two boxes it touches, and claim any that now has all four walls. The function returns how many boxes it claimed, and that number is the only thing the turn rule ever needs to look at.
    
        
    const newState = () => ({
  e: new Uint8Array(EDGES),                 // 0 = wall open, 1 = wall drawn
  owner: new Int8Array(NB).fill(-1),        // -1 = unclaimed, else player index
  score: [0, 0]
});
const sides = (st, b) => {                  // how many of box b's walls are drawn
  let n = 0; for (const id of BOX_EDGES[b]) if (st.e[id]) n++; return n;
};

function play(st, id, p){
  st.e[id] = 1;
  let got = 0;
  for (const b of EDGE_BOXES[id])
    if (st.owner[b] < 0 && sides(st, b) === 4){ st.owner[b] = p; got++; }
  st.score[p] += got;
  return got;                                // 0, 1, or 2 (an interior wall can close two)
}

    3
    The whole game loop is one if
    
        
    There is no timer, no physics, no animation loop needed for correctness — the entire game is: pick an undrawn wall, play it, and keep the turn if it claimed something. That single clause is what makes Dots and Boxes a real game instead of a coin flip: because a capture is free, a chain of already-3-walled boxes is taken in one unbroken run, so the size of what you give away matters far more than the wall you happen to like.
    
        
    const legal = st => { const m = [];
  for (let i = 0; i < EDGES; i++) if (!st.e[i]) m.push(i); return m; };

let turn = 0;                                // 0 = you, 1 = opponent
function move(st, id){
  const got = play(st, id, turn);
  if (got === 0) turn = 1 - turn;             // captured nothing -> hand it over
  //  got > 0    -> SAME player moves again
  return got;
}
// game over exactly when every wall is drawn; scores always add up to 16
const over = st => legal(st).length === 0;

    4
    Two predicates: what a wall closes, and whether it is safe
    
        
    Every ounce of strategy in this game is built from two little look-ahead functions. completes asks how many boxes a wall would close right now — that is your free money. isSafe asks the opposite: would this wall leave some box sitting on three walls, i.e. gift-wrapped for the opponent? Both tentatively set the bit, count, and unset it, so neither ever mutates the real board.
    
        
    function completes(st, id){                   // boxes this wall would close
  st.e[id] = 1; let n = 0;
  for (const b of EDGE_BOXES[id]) if (st.owner[b] < 0 && sides(st, b) === 4) n++;
  st.e[id] = 0; return n;
}
function isSafe(st, id){                      // leaves NO box on exactly 3 walls
  st.e[id] = 1; let ok = true;
  for (const b of EDGE_BOXES[id]) if (st.owner[b] < 0 && sides(st, b) === 3){ ok = false; break; }
  st.e[id] = 0; return ok;
}
const capturingMoves = st => legal(st).filter(id => completes(st, id) > 0);
const safeMoves      = st => legal(st).filter(id => completes(st, id) === 0 && isSafe(st, id));

    5
    Chains and loops — a flood fill over the leftovers
    
        
    Sooner or later safeMoves comes back empty, and what is left on the board is a set of chains and loops. Find them with an ordinary flood fill: two unclaimed boxes belong to the same region if the wall between them is still open. A region is a loop when every box in it has exactly two walls missing and none of those missing walls is on the outer border — otherwise it is a chain, with two ends that lead out.
    
        
    function regions(st){
  const seen = new Array(NB).fill(false), out = [];
  for (let b0 = 0; b0 < NB; b0++){
    if (st.owner[b0] >= 0 || seen[b0]) continue;
    const stack = [b0], comp = []; seen[b0] = true;
    while (stack.length){
      const x = stack.pop(); comp.push(x);
      for (const id of BOX_EDGES[x]) if (!st.e[id])            // still open -> connected
        for (const y of EDGE_BOXES[id])
          if (y !== x && st.owner[y] < 0 && !seen[y]){ seen[y] = true; stack.push(y); }
    }
    const loop = comp.every(x => 4 - sides(st, x) === 2)       // every box has 2 gaps
              && comp.every(x => BOX_EDGES[x].every(id =>
                   st.e[id] || EDGE_BOXES[id].length === 2));  // and no gap on the border
    out.push({ boxes: comp, size: comp.length, loop });
  }
  return out.sort((a, b) => a.size - b.size);                  // smallest first
}

    6
    The cascade, the smallest sacrifice, and the double-cross
    
        
    Three moves make an opponent that actually plays this game. cascade simulates greedily eating every box on offer, because captures are free turns. smallestSacrifice is what you do when every wall gives something away — open the cheapest chain. And doubleCross is the famous one: when only the last two boxes of a chain are on offer and other chains are still shut, you refuse them, drawing the far wall instead. The opponent takes those two in one move — and is then left with nothing free, so they must open the next chain.
    
        
    function cascade(st){                          // greedily eat everything on offer
  const c = clone(st), boxes = [];
  for (;;){
    const caps = capturingMoves(c);
    if (!caps.length) break;
    const before = c.owner.slice();
    play(c, caps[0], 0);
    for (let b = 0; b < NB; b++) if (before[b] < 0 && c.owner[b] >= 0) boxes.push(b);
  }
  return { boxes };
}
function smallestSacrifice(st){                // give away the least when cornered
  let best = -1, least = Infinity;
  for (const id of legal(st)){
    const c = clone(st); play(c, id, 0);
    const loss = cascade(c).boxes.length;
    if (loss < least){ least = loss; best = id; }
  }
  return best;
}
function doubleCross(st){                      // the hard-hearted handout
  const cas = cascade(st);
  if (cas.boxes.length !== 2) return -1;       // only for the LAST TWO of a chain
  const set = new Set(cas.boxes), free = legal(st);
  if (!free.some(id => !EDGE_BOXES[id].some(b => set.has(b)))) return -1;  // nothing else left
  for (const id of free)                       // the wall that closes NOTHING
    if (EDGE_BOXES[id].some(b => set.has(b)) && completes(st, id) === 0) return id;
  return -1;
}

    Exact endgame — memoised negamax over a bitmask
    
        
    Once few enough walls remain, stop guessing and solve it. Renumber the n remaining walls 0…n-1 so the whole position is a single integer bitmask, and search every line. The twist versus ordinary negamax is the extra turn: if a move captured, the same player continues, so you add the child score; if it captured nothing the sides swap, so you negate it. Memoise on the mask in a flat typed array — with 16 walls left that is 65,536 slots and a perfect answer in well under a tenth of a second.
    
        
    function exactBest(st){
  const free = legal(st), n = free.length;
  const cnt = new Int8Array(NB);                       // drawn walls per box, kept incrementally
  for (let b = 0; b < NB; b++) cnt[b] = sides(st, b);
  const taken = new Uint8Array(NB);
  for (let b = 0; b < NB; b++) taken[b] = st.owner[b] >= 0 ? 1 : 0;
  const adj  = free.map(id => EDGE_BOXES[id]);
  const size = 1 << n;
  const memo = new Int8Array(size), seen = new Uint8Array(size);

  function rec(mask){
    if (mask === 0) return 0;                          // no walls left -> nothing more to win
    if (seen[mask]) return memo[mask];
    let best = -128;
    for (let i = 0; i < n; i++){
      const bit = 1 << i; if (!(mask & bit)) continue;
      let got = 0, c0 = -1, c1 = -1;
      for (const b of adj[i]) if (++cnt[b] === 4 && !taken[b]){ taken[b] = 1; (got++ ? c1 = b : c0 = b); }
      const sub = rec(mask & ~bit);
      const val = got > 0 ? got + sub : -sub;          // captured -> go again; else swap sides
      if (c0 >= 0) taken[c0] = 0; if (c1 >= 0) taken[c1] = 0;
      for (const b of adj[i]) cnt[b]--;
      if (val > best) best = val;
    }
    seen[mask] = 1; memo[mask] = best; return best;
  }
  // top level: try each wall, keep the best
  let bestId = free[0], bestVal = -128;
  for (let i = 0; i < n; i++){ /* same do / rec / undo as above */ }
  return { id: bestId, value: bestVal };
}

    Stitching it together: the opponent, and clicking a wall
    
        
    The opponent is a short ladder of the pieces above: take free boxes (with the double-cross override), otherwise play a safe wall, otherwise open the smallest chain — and once the endgame fits, solve it exactly instead. Input is the last puzzle: the player clicks somewhere between two dots, not on a tidy grid cell, so map the pointer to the nearest undrawn wall by point-to-segment distance and accept it only inside a tolerance.
    
        
    function aiMove(st, level){
  const free = legal(st); if (!free.length) return -1;
  const LIMIT = level === "easy" ? 0 : level === "medium" ? 10 : 16;
  if (free.length <= LIMIT) return exactBest(st).id;         // solved, not guessed
  const caps = capturingMoves(st);
  if (caps.length){
    if (level === "hard"){ const dc = doubleCross(st); if (dc >= 0) return dc; }
    return caps[0];
  }
  const safe = safeMoves(st);
  if (safe.length) return safe[Math.random() * safe.length | 0];
  return smallestSacrifice(st);                               // cornered: give the least
}

function distToSeg(px, py, x1, y1, x2, y2){
  const dx = x2-x1, dy = y2-y1, L = dx*dx + dy*dy;
  let t = L ? ((px-x1)*dx + (py-y1)*dy) / L : 0;
  t = Math.max(0, Math.min(1, t));
  return Math.hypot(px - (x1+t*dx), py - (y1+t*dy));
}
